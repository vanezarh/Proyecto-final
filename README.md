# Sistema de Gestión de Productos

## Descripción
Este es un sistema de escritorio desarrollado en **Java** que permite la gestión completa de productos en un negocio. Incluye funciones para registrar ventas, controlar inventario, generar reportes y administrar usuarios.  

El proyecto utiliza una **base de datos MySQL** para almacenar información de productos, ventas y usuarios.  

## Funcionalidades
- Gestión de productos (Agregar, Editar, Eliminar)
- Registro de ventas
- Generación de reportes en PDF
- Control de usuarios y permisos
- Gráficas de ventas
- Interfaz amigable con ventanas de login y menú principal

## Tecnologías
- Lenguaje: **Java**
- Base de datos: **MySQL**
- Librerías:
  - iTextPDF (para generación de PDF)
  - JCalendar (para selección de fechas)
  - MySQL Connector (conexión a la base de datos)
- IDE recomendado: **NetBeans**
